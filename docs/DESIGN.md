# Дизайн Compass UI

Утверждено Семёном 2026-10-01: цветовая гамма нравится, держим её. Новые экраны
и компоненты делаем в этой палитре, новые цвета без необходимости не вводим.

Палитра общая с fleet-manager, чтобы продукты выглядели одним семейством.

## Логотип

```
COMPASS │ ROBOT
          CONTROL
Управляй своим роботом
```

- **COMPASS** — шрифт **Michroma** (локально из `@fontsource/michroma`, только латиница;
  робот может работать без интернета, поэтому никаких Google Fonts), заглавные,
  `letter-spacing: 0.14em`, градиент фирменного синего:
  светлая тема `brand-900 → brand-600`, тёмная `brand-200 → brand-400`. Класс `.wordmark`.
- **Черта** — 2 px, акцентный оранжевый `#f97316` (стрелка компаса из иконки).
- **ROBOT / CONTROL** — 8.5 px, semibold, заглавные, `letter-spacing: 0.18em`, slate-500 / slate-400.
- Слоган — 11 px, slate-500 / slate-400, переводится.
- Меню свёрнуто — одна буква **C** тем же шрифтом и градиентом.

## Цветовые гаммы

Настройки → Интерфейс → «Цветовая гамма» (хранится в браузере). **Синяя** — фирменная, по
умолчанию, таблица ниже. **Серая** — нейтральная шкала той же структуры (`brand-50…950`,
`src/lib/schemes.js`), акцент остаётся оранжевым, цвета режимов и карты — общие.
Гамма подменяет CSS-переменные `--color-brand-*`, поэтому все классы `brand-*`, логотип,
naive-ui (`primaryColor = brand-800`) и робот на карте меняются вместе. В тёмной теме у серой
гаммы ступени 700–900 светлее (`SCHEMES_DARK`): тёмно-серый на почти чёрном фоне не виден.

Внешний вид робота на карте (там же): дифференциальный, меканум, омни, автомобильный,
гусеничный, круг — `src/lib/robotShapes.js`, цвет — brand-800 / brand-400 (тёмная).

простую инверсию для тёмной темы не использовать — карта читается «наоборот».

## Правила

- Скругление 6 px (`rounded-md`), карточки — белые с границей slate-200, без теней.
- Скролл — внутри карточек и панелей; sidebar и topbar не уезжают.
- Крупные touch-цели (кнопки панелей `size="large"`, пункты меню 44 px) — UI работает на планшете.
- Обе темы проверять всегда.
